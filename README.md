# VOITHREAL\nVoice Orchestrated Intelligence Transforming Humanity REALity\n\nA voice-first personal companion for everyday care, routines, reminders, and accountability.\n\n## Included\n- Responsive marketing landing page.\n- Login, signup, and password-reset screens.\n- Local preview identity: any valid email and password of at least four characters can enter. This is not secure production authentication and does not send password-reset email.\n- Voice-first companion surface with no visible transcript or chat bubbles.\n- Browser speech recognition and speech synthesis.\n- Daily routines, task completion/deletion, task creation, progress, activity view, settings, and voice controls.\n- Browser notification reminders while the app is open.\n- Local persistence for preview profile and routines.\n- Server-side provider-neutral AI adapter with a local companion response when no model credentials are configured.\n- PWA manifest and SVG app icon.\n\n## Run\nNode.js 20.9+: npm install, then npm run dev. Open in Chrome and grant microphone/notification permissions.\n\n## Optional intelligence provider\nSet AI_BASE_URL, AI_API_KEY, and AI_MODEL as server-side environment variables. Never expose credentials in browser code or commit secrets.\n\n## Production integrations\nBefore public launch, connect real authentication, persistent storage, email delivery for password resets, secure user-scoped data, durable background scheduling, and push delivery. Browser reminders are best-effort while the app remains open. Speech recognition availability depends on browser/device support.\n
